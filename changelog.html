Version 0.2.5 BETA - November 7 2025

  • Added: Part Checklist Helper - A handy yellow question mark button appears next to the Home button in the builder
  • Added: Interactive checklist showing which parts you've added and which ones you still need for your build
  • Added: Smart part tracking that knows which parts are required, optional, or only needed when certain other parts are present
  • Added: Color-coded progress tracking - yellow for parts you need, green for parts you've already added
  • Added: Hover over any part in the checklist to see its attachment points pulse in the 3D view, making it easy to find where to attach things
  • Added: Click any part name in the checklist to see a detailed description of what that part is and why you might need it
  • Added: Cable Tower parts are now properly distinguished from ABL Wings and tracked separately in your build
  • Improved: Checklist intelligently shows child parts only when their parent parts are installed (like probe mounts only appearing when you have a wing)

Version 0.2.4 BETA - October 19 2025

  • Added: Front face support in Pre-Aligner tool - Mark both orientation and front faces for complete assembly orientation control
  • Added: Front face export in assembly JSON files for proper directional alignment
  • Added: Cookie consent banner for GDPR compliance with accept/decline options
  • Added: Assembly +N Namer tool for automatically generating variant JSON files for multi-assembly parts
  • Improved: Assembly validation now checks for missing circles, orientation faces, and pattern mismatches with clear error messages
  • Improved: Loading feedback with visual overlays and spinners when scanning for assembly variants and loading files
  • Fixed: Direct drive assemblies now maintain consistent forward orientation regardless of what they're mounted to
  • Fixed: Front face data now exports correctly from Pre-Aligner for all models in assembly

Version 0.2.3 BETA - October 13 2025

  • Added: Multi-assembly support - Parts used in multiple assemblies now show a menu to select which assembly to build
  • Added: Assembly selection menu integrated into normal navigation - choose between assembly variants just like browsing folders
  • Added: Load Build now accepts both ZIP files and standalone JSON files for easier sharing
  • Improved: Assembly alignment now automatically uses correct logic based on part type (gantry adapters, hotends, direct drives, etc.)
  • Improved: Menu icons now use Font Awesome for better compatibility and appearance
  • Improved: Build load success now shows as a green notification instead of a browser popup
  • Fixed: Back button in part menus now properly navigates through folders instead of closing immediately
  • Fixed: Menu navigation state is now correctly maintained when browsing through subfolders
  • Fixed: Load Build button no longer appears twice on mobile devices

Version 0.2.2 BETA - October 11 2025

  • Added: JSON Coverage Tracker - New page showing which parts still need alignment data for the builder
  • Added: "View Details" button in the Part Coverage stats box for easy access to the tracker
  • Added: Organized folder view in tracker - click to expand and see missing parts by category
  • Improved: JSON tracker now loads much faster by caching data between visits
  • Added: Refresh button in tracker to update data after new parts are added

Version 0.2.1 BETA - October 7 2025

  • Added: Save and Load Build feature - Export builds as ZIP files containing a build.json that allows you to load and reconstruct complete assemblies later
  • Added: Load Build button on desktop (above Download Assembly) and mobile builder menu for importing saved builds
  • Added: Multi-part assembly support - Builder can now load multi-component assemblies as single models (currently available for gantry adapters)
  • Added: Assembly parts are displayed in random pastel colors to easily distinguish individual components
  • Added: Pre-Aligner tool - New dedicated page for creating multi-part assembly definitions with precise positioning
  • Added: CREDITS.txt file automatically generated in exported ZIPs listing all model authors and download links
  • Added: Default credit attribution to MediaMan3D for models without explicit credit data
  • Improved: Build loading system reconstructs attachments hierarchically, ensuring risers, spacers, and direct drives load in correct order
  • Improved: Double-click to remove now works on any part of a multi-part assembly to remove the entire assembly group
  • Improved: Enhanced attachment point matching for better compatibility when loading builds with risers and spacers

Version 0.2.0 BETA - October 4 2025

  • Added: Mobile-friendly interface with collapsible bottom menu for tools and options
  • Added: Mobile part selection menus now appear at top of screen instead of following attachment points
  • Added: Mobile move tool with tap-based controls - tap to select parts, tap arrows to move in 1mm increments
  • Added: Double-tap to remove parts functionality on mobile devices
  • Added: Larger, touch-friendly arrows on mobile for easier interaction with move tool and part adjustments
  • Improved: Move tool now gracefully exits when clicking attachment points instead of showing errors
  • Improved: Bidirectional move arrows - can now move parts in both positive and negative directions on all axes

Version 0.1.9 BETA - October 3 2025

  • Refactored: Complete codebase restructure - separated monolithic app.js into modular components (models.js, scene.js, events.js, ui.js, state.js, filesystem.js, etc.)
  • Fixed: Direct drive mount alignment inconsistency - all direct drives now mount with consistent orientation regardless of parent type
  • Fixed: Enhanced alignment system to properly handle coordinate transformations without inheriting parent rotations
  • Fixed: Memory leak issue where secondary attachments weren't properly cleaned up when removing models
  • Fixed: Attachment type classification bug where direct drives were misidentified as spacers based on filename filtering
  • Improved: Enhanced alignment logic now correctly translates JSON coordinate systems to global builder coordinates
  • Added: Custom folder support with yellow star icons for easy identification
  • Improved: Move tool icon changed from wrench to directional arrows for better user understanding

Version 0.1.8 BETA - September 1 2025

  • Fixed: Major direct drive mount alignment fix using position-based face detection to correctly orient front faces toward camera
  • Fixed: Resolved backwards mounting issues for Creality direct drive mounts and select Bondtech models
  • Added: Issue Tracker page for bug reports and feature requests
  • Added: Contributors menu showcasing project contributors with slide-up interface
  • Added: Navigation buttons on main menu for quick access to Marker tool and Tracker
  • Added: Home button in builder interface for easy return to main menu
  • Added: JSON coverage statistics showing percentage of STL files with alignment data
  • Marker Tool: Added floating home button for easy navigation back to main site

Version 0.1.7 BETA - August 30 2025

  • Improved: Enhanced alignment system for direct drive mounts, hotend mounts, and risers with better face data support
  • Fixed: Simplified mounting logic to align hole patterns correctly and ensure front faces point toward camera
  • Added: Backwards compatibility for legacy JSON format while supporting enhanced face data with position and dimensions
  • Marker Tool: Visual improvements and enhanced JSON exports with face position and dimensional data
  • Marker Tool: Added support for front face and orientation face detection with enhanced geometric data
  • Marker Tool: Added working reset button functionality
  • Marker Tool: Added ability to load and reload existing JSON files for editing
